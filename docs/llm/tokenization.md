## BBPE (Byte-level BPE)

**论文**: [Neural Machine Translation with Byte-Level Subwords (2019)](https://arxiv.org/pdf/1909.03341)

### 核心思想

BBPE 用 **byte（字节）** 构建最基础词表，将 BPE 从字符级别扩展到字节级别，在字节序列上使用 BPE 算法进行相邻合并。

BBPE 与 BPE 构建词表的流程基本一致，只是在字节级别进行合并，需要在 BPE 的基础上把单个字符转化为单个字节再进行合并。

### BPE vs BBPE 示例

以 "你好" 为例：

| 方式 | 表示 |
|------|------|
| BPE (字符级) | `你` `好` |
| BBPE (字节级) | `\xe4` `\xbd` `\xa0` `\xe5` `\xa5` `\xbd` |

### BBPE 构建词表步骤

1. **初始化**: 先将单词拆成单个字符，再将字符转化为单个字节，构建初始字节词表
2. **合并**: 找出频率最高字节对合并成新字节加入词表，同时在语料库中替换原字节对，新字节还能参与后续合并
3. **迭代**: 不断重复上述步骤，直到词表字节数达预设阈值 V 或剩下字节对频率为 1

### BBPE 相比 BPE 的优势

| 特性 | 说明 |
|------|------|
| **跨语言通用性** | 字节级别操作，可以更容易地处理多种语言的文本，而不需要为每种语言单独构建词表，同时显著压缩词表的大小，提高了计算效率 |
| **更好的解决 OOV 问题** | 将字符统一映射至字节空间，使相同词表容量下覆盖更广的字符及组合，可以更高效兼容 OOV 问题，同时兼顾词表紧凑性与表达能力 |

### 关键结论

> **现代大模型的 BPE 一般情况下说的都是 BBPE**。

例如 GPT-2、GPT-3、LLaMA 等模型实际使用的都是基于字节级别的 BPE 变体。
