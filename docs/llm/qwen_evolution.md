> 从 Qwen1 到 Qwen3-2507：架构改进与训练方法演进

```

  │            │             │             │             │             │
```

## Qwen1（2023年8月）

### 模型结构

| 特性 | 说明 |
|-----|------|
| **基础** | 类似 LLaMA 的 Transformer 架构 |
| **位置编码** | **RoPE** (Rotary Position Embedding) |
| **归一化** | **PreRMSNorm** |
| **激活函数** | **SwiGLU** |
| **偏置** | 移除 QKV 线性层外的 **bias** |

### 训练方法

| 方法 | 说明 |
|-----|------|
| **注意力加速** | **FlashAttention** |
| **优化器** | **AdamW** + **BF16** 混合精度训练 |
| **上下文长度** | 训练时 2048，**NTK 插值**外推到 8192 |

---

## Qwen1.5（2024年4月）

### 模型结构改进

| 特性 | 说明 |
|-----|------|
| **GQA** | 引入 **GQA** (Grouped Query Attention)，仅 **32B** 模型使用 |
| **MoE** | 加入 MoE 系列（**14B-A2.7B**）：<br>• 4个共享专家 + 60个细粒度专家<br>• 每次推理激活 **4个专家** |

### 训练方法

| 方法 | 说明 |
|-----|------|
| **后训练** | **PPO** 与 **DPO** 共同训练 |
| **上下文** | 全系列支持 **32K** |

---

## Qwen2（2024年9月）

### 模型结构改进

| 特性 | 说明 |
|-----|------|
| **GQA** | **全系列**使用 GQA，**KV 缓存减少 40%** |
| **长文本** | **YaRN** + **DCA** (Dual Chunk Attention，双块注意力机制) |

### 训练方法

#### 预训练

| 项目 | 内容 |
|-----|------|
| **数据规模** | 从 3T tokens 拓展至 **7T tokens** |
| **数据增强** | 高质量代码、数学、多语言数据 |

#### 后训练

| 阶段 | 方法 | 说明 |
|-----|------|------|
| **SFT** | 指令微调 | • 超 **50万** 标注数据集<br>• 涵盖指令跟随、编码、数学、逻辑推理、角色扮演、多语言<br>• 两个时期微调，逐步降低学习率 |
| **RLHF** | 离线阶段 | 预编译偏好数据集，使用 **DPO** 训练 |
| **RLHF** | 在线阶段 | • 奖励模型实时迭代<br>• 选取最受欢迎/最不受欢迎数据形成偏好对<br>• 采用**在线合并优化器**对齐人类偏好 |

---

## Qwen2.5（2025年1月）

### 模型尺寸

**全系列 7 种尺寸**：0.5B、1.5B、3B、7B、14B、32B、**72B**

### 训练方法

#### 预训练

| 项目 | 内容 |
|-----|------|
| **数据规模** | 从 7T tokens 拓展至 **18T tokens** |
| **数据增强** | 强化代码和数学数据集，增强推理能力 |

#### SFT

| 项目 | 内容 |
|-----|------|
| **长文本** | 构建长文本数据集 |
| **输出长度** | 从 2K 扩展至 **8K** |

#### RL（强化学习）

| 类型 | 方法 | 数据/目标 |
|-----|------|----------|
| **离线 RL** | **DPO** | 高质量正负样本对，约 **15万对** |
| **在线 RL** | **GRPO** | 基于奖励模型优化真实性、帮助性、简洁性等偏好指标 |

#### 长文本能力

**YaRN + DCA 可实现 100万 tokens 的超长文本适配**

---

## Qwen3（2025年4月）

### 模型结构改进

| 模型类型 | 改进 |
|---------|------|
| **Qwen3 Dense** | 引入 **QK-RMSNorm** |
| **Qwen3 MoE** | • 取消共享专家<br>• 更细粒度的分割专家<br>• **全局批量负载平衡损失** |
| **动态思考** | **单模型**可动态调节思考/非思考模式 |
| **大尺寸** | • **Qwen3-235B-A22B**<br>• **Qwen3-Coder-480B-A35B** |

### 训练方法

#### 预训练

| 项目 | 内容 |
|-----|------|
| **数据规模** | 从 18T tokens 拓展至 **36T tokens** |

#### 后训练（四阶段）

```
阶段1: CoT冷启动微调
    ↓
阶段2: GRPO 对 query-verifier 数据集强化推理
    ↓
阶段3: 用无推理路径数据学习思考/非思考能力
    ↓
阶段4: 强化学习提升特定场景应用能力
```

| 阶段 | 方法 | 目标 |
|-----|------|------|
| **阶段1** | CoT 冷启动微调 | 建立基础推理能力 |
| **阶段2** | **GRPO** | 对 query-verifier 数据集进行**强化推理** |
| **阶段3** | SFT | 用**无推理路径**数据学习思考/非思考模式切换 |
| **阶段4** | RL | 提升特定场景应用能力 |

#### 模型蒸馏

| 方法 | 说明 |
|-----|------|
| **KL 散度** | 将小模型与大模型对齐 |

---

## Qwen3-2507（2025年7月）

### 模型结构改进

| 特性 | 说明 |
|-----|------|
| **思考模式** | 将**思考/非思考模型分离**，不再使用单模型切换 |
| **上下文** | 支持超长文本 **256K** |
| **专用模型** | • **Qwen3-Coder**（编程专用）<br>• **Qwen-MT**（翻译专用） |

## 演进总结

### 1. 架构演进

| 时期 | 重点 | 关键改进 |
|-----|------|---------|
| **Qwen1 ~ Qwen2** | 结构优化 | RoPE → GQA → MoE → YaRN+DCA |
| **Qwen2.5 ~ Qwen3** | 推理能力 | 动态思考 → QK-RMSNorm → 思考分离 |

### 2. 数据规模增长

```
Qwen1:     ?
   ↓
Qwen2:    7T tokens
   ↓
Qwen2.5: 18T tokens
   ↓
Qwen3:   36T tokens
```

**2年时间里数据规模增长约 5 倍**

### 3. 后训练复杂度演进

| 版本 | 后训练流程 |
|-----|-----------|
| Qwen1 | 基础 SFT |
| Qwen1.5 | PPO + DPO |
| Qwen2 | SFT + 两阶段 RLHF（离线DPO + 在线DPO） |
| Qwen2.5 | SFT + 离线DPO + 在线GRPO |
| Qwen3 | **四阶段**：CoT冷启动 → GRPO推理 → 思考模式学习 → RL场景优化 |
| Qwen3-2507 | 专用模型分离训练 |

### 4. 关键趋势

1. **前期（Qwen2.5 以前）**：主要关注**架构创新**
   - GQA、MoE、DCA 等高效注意力机制
   - 长文本外推技术（NTK、YaRN）

2. **后期（Qwen2.5 以后）**：主要关注**推理能力**
   - 受 o1 和 DeepSeek 影响
   - 后训练流程越来越复杂
   - **思考/非思考模式**的动态控制与分离
   - 数据质量比数量更重要

### 5. 现状

> **各厂都没公开数据集，只是介绍了训练流程，细节还是不知道**

- 模型架构相对透明
- 训练数据和方法成为核心竞争力
- 推理能力的提升依赖高质量标注数据和复杂后训练流程

## 面试要点

### 常见问题

**Q1: Qwen 模型演进的关键节点？**
- A: 
  - Qwen1: 基础架构（RoPE, SwiGLU）
  - Qwen1.5: GQA、MoE
  - Qwen2: 全系列GQA、YaRN+DCA
  - Qwen2.5: 18T数据、DPO+GRPO
  - Qwen3: 动态思考、36T数据、四阶段后训练
  - Qwen3-2507: 思考模型分离

**Q2: Qwen2 的 KV 缓存优化？**
- A: 全系列使用 GQA，KV 缓存减少 **40%**

**Q3: Qwen3 的四阶段后训练是什么？**
- A:
  1. CoT 冷启动微调
  2. GRPO 强化推理
  3. 无推理路径数据学习思考/非思考
  4. RL 提升特定场景能力

**Q4: 为什么 Qwen3-2507 将思考模型分离？**
- A: 单模型动态切换的局限性，分离后专用模型在各自领域表现更好

**Q5: Qwen 模型上下文长度的演进？**
- A:
  - Qwen1: 2048 → 8192 (NTK)
  - Qwen1.5: 32K
  - Qwen2.5: 100万 (YaRN+DCA)
  - Qwen3-2507: 256K
