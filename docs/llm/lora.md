# LoRA (Low-Rank Adaptation)

LoRA 相关知识点，包括原理、初始化策略、与 Adapter 对比等。

---

## 1. 基本原理

LoRA 在原线性层权重 $W_0$ 上添加一个低秩矩阵分解项进行微调：

$$h = W_0 x + \frac{\alpha}{r} B A x$$

其中：
- $W_0 \in \mathbb{R}^{d_{out} \times d_{in}}$：预训练的原始权重（冻结）
- $A \in \mathbb{R}^{r \times d_{in}}$：**降维层**（可训练）
- $B \in \mathbb{R}^{d_{out} \times r}$：**升维层**（可训练）
- $r \ll \min(d_{in}, d_{out})$：低秩（通常 4~64）
- $\alpha$：缩放因子

**计算流程**：输入 $x$ 先经 $A$ 压缩到低维空间（秩 $r$），再经 $B$ 映射回输出维度。

---

## 2. 初始化策略

| 矩阵 | 初始化方式 | 作用 |
|------|-----------|------|
| **A（降维）** | 高斯随机 / Kaiming | 提供随机的低秩基底 |
| **B（升维）** | **全 0 矩阵** | 训练开始时适配项为 0 |

### 为什么 B 初始化为 0？

1. **训练稳定性**：初始时 $BA = 0$，输出与预训练模型完全一致，避免初始阶段偏移过大
2. **渐进学习**：随着训练，$BA$ 逐渐学习有效的低秩更新
3. **可回退性**：若效果不佳，可直接去掉 LoRA 权重，回退到原始模型

---

## 3. LoRA vs Adapter

| 特性 | LoRA | Adapter |
|------|------|---------|
| **修改方式** | 在原线性层上加低秩矩阵 | 新增额外的线性层 |
| **网络结构** | 不改变层数，修改现有层 | 增加新层 |
| **推理开销** | 可将 $W_0 + BA$ 合并，无额外开销 | 必须顺序执行新增层，有额外开销 |
| **参数量** | $r \times (d_{in} + d_{out})$ | 通常更多（取决于 Adapter 设计） |

**一句话区别**：Adapter 是"加新层"，LoRA 是"改旧层"。

---

## 4. 应用位置

通常对以下权重矩阵应用 LoRA：
- Transformer 中的 **Q、K、V 投影矩阵**
- **Output 投影矩阵**
- **FFN 中的线性层**（可选）

**注意**：Embedding 层和 LM Head 通常不使用 LoRA。

---

## 5. 关键超参数

| 参数 | 作用 | 典型值 |
|------|------|--------|
| $r$（秩） | 低秩维度，越大表达能力越强 | 4, 8, 16, 64 |
| $\alpha$ | 缩放因子，控制 LoRA 权重的影响 | 通常设为 $r$ 或 $r/2$ |
| dropout | LoRA 层的 dropout 率 | 0.0 ~ 0.1 |

**缩放因子**：实际缩放为 $\alpha / r$，当 $\alpha = r$ 时等价于无额外缩放。
